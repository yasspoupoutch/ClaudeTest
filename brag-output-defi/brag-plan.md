# CNSNN — vidéo 2 : « Le groupe »

**Format :** TikTok 1080×1920, 30 i/s, 21,5 s. **Ton :** fun et rapide, avec des coupes franches.

**Angle :** CNSNN se joue entre amis. Dans une conversation de groupe, Léa partage la vraie image de partage de l'appli
(ShareCard : CONSONNE, « CHCRT », « Trouvé en 0:41 », « Trouverez-vous les voyelles ? »). Le groupe s'énerve, « Vous » lance
un défi (fonction Défis : 5 mots, code de 6 caractères, le plus rapide gagne), le gagne, et la chute révèle le mot.

| Temps | Scène |
|---|---|
| 0–1 s | **Accroche.** L'image de partage CHCRT arrive en grand, puis prend sa place dans la conversation. |
| 1–7,6 s | Le groupe réagit : « CHCRT ??? 😭 », « chocolat ? non attends », « pas de spoil 🤫 ». « Vous » répond avec un défi, code K7Q2XM. |
| 7,6–8,5 s | Écran or plein cadre : « DÉFI LANCÉ ». |
| 8,5–11,6 s | Les 5 mots en rafale : FRAISE, CITRON, BRIOCHE, QUICHE, MACARON (vraies cartes), chrono jusqu'à 0:38. |
| 11,6–14,3 s | Résultats dans le groupe : Vous 0:38 👑, Léa 0:52. « NON 😭😭 », « revanche demain. » |
| 14,3–17,6 s | Trois coupes franches : UN MOT PAR JOUR. / LE MÊME POUR TOUS. / VOS AMIS À BATTRE. (phrase du site) |
| 17,6–21,5 s | CNSNN devient CONSONNE. « Défiez vos amis. » Chute : Léa, « c'était CHOUCROUTE 💀 ». |

**Son :** ré mineur à 128 BPM. « Pop » de messages dans la tonalité, montée puis coup fort sur « DÉFI LANCÉ »,
une note qui monte à chaque mot trouvé, accords francs sur les coupes, cloches sur les voyelles du logo.

**Données :** prénoms, groupe, temps et code de défi fictifs. Mots et indices issus de Shared/cards.tsv. Aucune donnée réelle.
